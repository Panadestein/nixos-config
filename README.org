Welcome to my [[https://nixos.org/][NixOS]] system flake, with [[https://nix-community.github.io/home-manager/][Home Manager]] 
shaping the user environment.

The machine is named [[https://en.wikipedia.org/wiki/Cyrus_Smith][cyrus]], after Verne's engineer and my childhood hero.
Its Wayland desktop uses [[https://hypr.land/][Hyprland]] exclusively. The config emphasises coherence, robustness, and
minimalism: no bullshit features for its own sake.

Visually, the system draws its character from the landscapes of [[https://en.wikipedia.org/wiki/Ernst_Ferdinand_Oehme][Ernst Ferdinand Oehme]],
an unsung hero of the German Romantic period. The tracked wallpaper collection, together with notes on the works, lives
[[file:home/assets/wallpapers/oehme/README.md][here]].


** Rebuilding

Run commands from the repository root. First validate the flake and build the
system and Home Manager configuration without activating it:

#+begin_src bash
  nix flake check --no-write-lock-file
  nix build --no-link .#nixosConfigurations.cyrus.config.system.build.toplevel
#+end_src

A build checks generated files and package dependencies; it cannot exercise docking
or suspend on hardware. New files must be added with =git add= before a Git-backed flake
can see them.

Apply the configuration:

#+begin_src bash
  sudo nixos-rebuild switch --flake .#cyrus
#+end_src

Log out and back in after changes to the session environment or compositor.
=Super+Ctrl+R= reloads the /installed/ Hyprland configuration; repository edits
take effect after rebuilding.

Update one input at a time, then repeat the checks above:

#+begin_src bash
  nix flake update <INPUT>
#+end_src

or all of them together:

#+begin_src bash
  nix flake update
#+end_src

Keep the existing =stateVersion= values when upgrading: they describe compatibility
defaults, not the desired NixOS release.

** Desktop essentials

=Super+F1= shows the shortcut list generated from the bindings themselves. Some examples:

| Shortcut          | Action                         |
|-------------------+--------------------------------|
| =Super+Return=    | Ghostty with Fish              |
| =Super+R=         | Application launcher           |
| =Super+P=         | Password menu (copy)           |
| =Super+Shift+P=   | Password menu (type)           |
| =F12=             | Fish drop-down terminal        |
| =Super+C=         | Numbat calculator scratchpad   |
| =Super+F=         | Yazi                           |
| =Print=           | Region screenshot              |
| =Super+Shift+W=   | Wallpaper chooser              |
| =Super+Ctrl+W=    | Next painting                  |
| =Super+O=         | Lock                           |
| =Super+Ctrl+Q=    | Log out through UWSM           |

Idle locking starts at ten minutes, display power-off at eleven, and suspend at thirty.
Kanshi selects the Lenovo display when docked and the laptop panel otherwise.
For session problems, start with =hyprctl configerrors=,
=systemctl --user --failed= and =journalctl --user -b -u hypridle -u kanshi -u waybar=.

** Development shells

The principal flake provides small, current nixpkgs-based development environments:

| Command                          | Environment                                      |
|----------------------------------+--------------------------------------------------|
| =nix develop=                    | Nix formatting and static analysis               |
| =nix develop .#python=           | Scientific Python and Jupyter                    |
| =nix develop .#c-cpp=            | C/C++ compilers, build tools and debugging       |
| =nix develop .#fortran-mpi=      | Fortran, Open MPI, fortls and fypp               |
| =nix develop .#julia=            | Julia                                            |

Home Manager enables direnv and nix-direnv for Bash, Fish and Zsh. The repository's
=.envrc= selects the default maintenance shell; approve it once with =direnv allow=.
